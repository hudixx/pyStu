# 选修 B5 第 2 课：从 Counter 看次数

要加总的次数是一个数字。从日志里数「下单」出现了几次，句子一改，数就断了。

对照 Micrometer 的 `Counter`。这一课自己写一个，把加一和读出数字露在外面。不装 Prometheus。

运行：

```bash
PYTHONUTF8=1 python B5-02-次数是数字/02_指标.py
```

应看到：

```text
买牛奶 2
买面包 1
```

---

## 1. 标签是分组，不是每一单

`add("买牛奶")` 两次，这个标签的数字是 2。没加过的标签，`get` 是 0，不抛错。

标签用来分组。用用户 id 或订单号当标签，每来一个新 id 就多一条序列，条数跟着订单涨，加总也失去意义。每一单去日志里查，带上后面课的请求号。次数只按你真的要比较的那几类来分，比如标题、成功还是失败。

生产里换成 `prometheus_client` 的 `Counter`，还是 `add` 和按标签读。那个库把计数器登记在全局表上，同名再建一次会抛。测试里要记得拆掉。本课不碰那个表。

---

## 本课肌肉记忆

1. 次数是数字，不是一句日志
2. 没出现过的标签读出来是 0
3. 标签不要用用户 id 或订单号
