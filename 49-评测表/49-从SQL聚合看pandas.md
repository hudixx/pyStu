第 44 课的两版分数，落成一张表之后才能对比。pandas 在这里只做三件事：读 csv、过滤、按版本求通过率。不是转数据分析。

```bash

```

`评测结果.csv` 就是第 44 课那两版的结果，已经写在同目录。应看到引用版通过率 `1.0`，简短版 `0.0`，简短版失败 `3` 条。

---

## 1. 三行就够

| pandas | SQL |
|---|---|
| `read_csv` | 把 csv 装进一张表 |
| `frame["版本"] == "简短版"` | `WHERE 版本 = '简短版'` |
| `groupby("版本")["通过"].mean()` | `SELECT 版本, AVG(通过) GROUP BY 版本` |

`&` 两边要加括号。`and` 不能用来并排两个列条件，会报错。对照 SQL 用 `AND`，这里的运算符是 `&`。

通过率是改提示词之前和之后的证据。「又问了一次感觉更好」没有这张表。
