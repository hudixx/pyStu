## 题 1：三元表达式

写函数 `sign_of(n: int) -> str`：

- `n > 0` 返回 `"正"`
- 否则返回 `"非正"`

**必须用三元表达式**，不要写 `if/else` 块。
分别打印 `sign_of(3)` 和 `sign_of(0)`。

想清楚顺序：Python 是 `真值 if 条件 else 假值`。

## 题 2：enumerate

对 `langs = ["java", "python", "go"]`，用 `enumerate` 打印成：

```text
1. java
2. python
3. go
```

下标从 1 起，不要自己 `i + 1`（可以用 `start=1`）。

## 题 3：推导式

用 **一条列表推导式** 得到所有偶数的平方，并打印。
期望：`[0, 4, 16, 36, 64]`

不要写 `for` 循环 + `append`。
