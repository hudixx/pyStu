# 选修 B2 第 1 课：从持久化上下文看过期

`commit` 之后，对象上的字段会过期。会话还开着，再点一次会重新查。会话关了再点，就脱离了。

运行：

```bash
PYTHONUTF8=1 python B2-01-提交后过期/01_过期.py
```

应看到：

```text
提交后还在会话里 hudi
这条读取 1
已经加载过 hudi
没加载过 DetachedInstanceError
```

---

## 1. 过期不是已经脱离

| 时机 | 再点名字 | Java |
|---|---|---|
| `commit` 之后，`with` 还没结束 | 再发一条 `SELECT`，读到值 | 持久化上下文还在，可以再加载 |
| 会话里已经重新加载过，然后 `with` 结束 | 还读得到。这份值留在对象上 | 字段已经初始化过，detached 上仍能读这个字段 |
| 提交后从没再点过，然后 `with` 结束 | `DetachedInstanceError` | 字段没加载，会话又关了，没法再查 |

默认 `expire_on_commit=True`。提交成功就把内存里的字段标成过期，避免你拿着一份已经旧了的值继续用。

这不是 Open Session In View。那个做法是请求结束前一直不关会话，页面上点懒字段碰巧还能查。请求被拖长，N+1 更难看见。这一课不那么做。

---

## 本课肌肉记忆

1. `commit` 之后字段过期
2. 会话还开着，再点会重新加载，这份值会留下
3. 过期又脱离，再点才会 `DetachedInstanceError`
