## 题 1：生成器

写函数 `evens(limit: int)`，用 `yield` 依次给出 **小于 limit 的偶数**（从 0 起）。

```python
list(evens(7))   # 期望 [0, 2, 4, 6]
```

不要先造完整列表再 return，必须 `yield`。

## 题 2：装饰器

写装饰器 `twice`：调用被装饰函数 **两次**，返回 **第二次** 的返回值。

```python
@twice
def ping() -> str:
    print("pong")
    return "ok"

print(ping())
```

期望打印两行 `pong`，最后 `print(ping())` 得到 `ok`。
用 `@functools.wraps`。
