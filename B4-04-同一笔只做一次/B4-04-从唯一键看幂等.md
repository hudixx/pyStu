# 选修 B4 第 4 课：从唯一键看幂等

队列至少会送一次。工人做完副作用、还没把消息拿掉就死了，这同一笔会再来。第二次不能再加一行订单。

运行：

```bash
PYTHONUTF8=1 python B4-04-同一笔只做一次/04_幂等.py
```

应看到：

```text
完成
已经做过
完成
['买牛奶', '买面包']
```

---

## 1. 一条命令抢这个号

`set(..., nx=True)` 只在键不存在时写入。写成了返回 `True`。键已经在，返回 `None`，不是 `False`。

先 `get` 看有没有、再 `append`，中间可以插进另一个进程，两边都看见「没有」。`nx` 是一条命令，只有一个能写成。

键要带消息号，例如 `done:A-1`。不要所有订单共用一个键。

这个键在 `fakeredis` 里，进程结束就没了。下单、付钱要把「做过」记在数据库的唯一键上。Redis 可以当加速，不能当唯一的账。

上一课放进死信的消息，不会自己回到 `jobs`。人若把它重新放回去，处理函数还是要走这一课的判断。

## 本课肌肉记忆

1. 同一消息号的副作用只做一次
2. 用 `SET NX` 这一条命令，不要先查再写
3. 能丢的缓存可以放 Redis，不能丢的账放数据库唯一键
