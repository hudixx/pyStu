先进入本目录再运行示例（很重要，否则 import 可能找不到）：

```bash
cd 05-模块包与虚拟环境
PYTHONUTF8=1 python 05_模块.py
```

## 题 1：自己写一个模块并导入

`my_util.py` 里写函数 `repeat(text: str, times: int = 2) -> str`，返回 `text * times`。
（就是第 03 课那题的正确版。）

`05_练习.py` 里：

```python

```

## 题 2：`__name__`

在 `my_util.py` 顶层加一行：

```python
print("my_util.__name__ =", __name__)
```

再分别：

```bash
PYTHONUTF8=1 python my_util.py
PYTHONUTF8=1 python 05_练习.py
```

两次打印的 `__name__` 分别是什么？写在 `05_练习.py` 的注释里。
