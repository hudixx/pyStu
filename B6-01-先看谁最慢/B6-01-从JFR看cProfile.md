# 选修 B6 第 1 课：从 JFR 看 cProfile

先量出谁最慢，再改。循环写在哪个函数里，就该看到哪个名字，不要凭「这段看起来复杂」去挑。

`cProfile` 要把程序跑在它下面。已经在跑、不能重启的进程，它看不见。那种情况用 `py-spy`，下一课说明里会写。本课不安装它。

运行：

```bash
PYTHONUTF8=1 python B6-01-先看谁最慢/01_剖析.py
```

应看到：

```text
最慢 slow
```

不打印秒数。秒数每次会浮动，名字不会。

---

## 1. 自身时间

`tottime` 是这个函数自己的语句花的时间，不含它叫出去的那些函数。这一课 `slow` 自己在做循环，`fast` 只是 `return 1`，所以最长的是 `slow`。

`cProfile` 会让程序变慢。它把每次调用都记下来。数字是来比较谁更慢的，不是线上的真实耗时。
