## 题 1：合法 JSON

pydantic 模型至少两个字段：`name: str`、`score: int`（0～100）。
`response_format={"type": "json_object"}` 打假模型，`model_validate_json` 之后打印 `name` 和 `score`。
期望 `hudi` 和 `70`（假模型写死的）。

## 题 2：脏 JSON 必须失败

user 消息含 `TRIGGER:BADJSON`。抓住 `ValidationError`（或你实际看到的解析异常），打印一句 `失败`。
**不要**失败后返回默认 `Person`。
