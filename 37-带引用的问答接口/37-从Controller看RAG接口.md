# 第 37 课：从 Controller 看带引用的问答

阶段七收口：一个接口，问手册里的事实，返回答案和出处；手册里没有的，回答「不知道」，出处为空。

运行：

```bash
PYTHONUTF8=1 python 37-带引用的问答接口/37_app.py
```

不需要 uvicorn，也不打模型。TestClient 和第 20 课一样，不占端口。

---

## 1. 启动时建索引，请求里只带问题

`手册.md` 在 import 时读入、切块、算向量。`POST /ask` 只收 `question`。

对照：Spring 启动时加载一份只读缓存，而不是每个请求把文件再读一遍。手册改了要重启，本课先接受这一点。

这里用普通 `def`。没有 `await` 就不要写成 `async def`（第 24 课）。

---

## 2. 返回两样东西

```json
{"answer": "购买后 7 天内可以退款。逾期不受理。（来源：退款）", "sources": ["退款"]}
```

不知道时：

```json
{"answer": "不知道", "sources": []}
```

`sources` 为空，调用方就知道这不是从手册里查到的。不要 200 一个编出来的地址。

真要模型改写时，把第 31 课的 chat 接在「sources 非空」之后。system 只写规则，资料和问题放在 user。本课先不接，避免假模型的回声把引用弄乱。

---

## 本课肌肉记忆

1. 切块 → 向量 → 检索 → 有出处才回答
2. 索引在启动时建
3. 没有 `await` 的接口用普通 `def`
4. 能说出：为什么按标题切，而不是整篇一块

阶段八是工具调用。说「开始阶段八」再写。不要把这次问答包成一个自己循环的 Agent。
