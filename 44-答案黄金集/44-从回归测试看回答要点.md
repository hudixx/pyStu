# 第 44 课：从回归测试看回答要点

第 36 课的黄金集评检索出处。这一课评回答正文里有没有**要点**。改了提示词或换了一版回答，就重跑同一批题。

运行：

```bash
PYTHONUTF8=1 python 44-答案黄金集/44_黄金集.py
```

引用版应是 `通过 3/3`：退款里有 `7`，电话里有 `400-100-1000`，地址题是「不知道」。
简短版应是 `通过 0/3`。它更礼貌，但数字没了，地址还编了北京。

---

## 1. 要点是断言，不是文采

```text
退款几天     正文必须含「7」
客服电话多少  正文必须含「400-100-1000」
公司地址在哪  必须拒答，不能出现具体城市
```

对照 JUnit 的 `assertThat(answer).contains("7")`。没有这行，你只能说「感觉简短版更好」。简短版把要点删了，回归会红。

要点写死在 `GOLD` 里。换一种问法、又没有对错标准，改坏了看不出来。

---

## 2. 和第 36 课不要混

| | 第 36 课 | 这一课 |
|---|---|---|
| 评什么 | 出处是不是「退款」那一节 | 正文里有没有「7」 |
| 出处对、正文把天数说丢 | 仍算过 | 算不过 |
| 谁打分 | 规则 | 还是规则，不是另一个模型 |

文采、是否礼貌，不进这张表。下一课会看见：请一个模型来打分，它自己也会错。

---

## 本课肌肉记忆

1. 同一批题，改一版就重跑
2. 断言写在要点上，不写在「好不好读」上
3. 拒答也是一条断言
