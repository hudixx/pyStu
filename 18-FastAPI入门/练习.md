---

## 题 1：GET

`GET /ping` 返回 `{"msg": "pong"}`。

## 题 2：GET + query

`GET /repeat?text=go&times=3` 返回 `{"result": "gogogo"}`。
`times` 默认 2，类型 int。

## 题 3：POST + pydantic

请求体：

```json
{"title": "买牛奶"}
```

`title` 最短 1 个字符。返回：

```json
{"id": 1, "title": "买牛奶", "done": false}
```

id 写死 `1` 即可，本课不要求持久化。

## 题 4：对照题（写在注释里）

FastAPI 里一个函数参数，怎样区分它是 query、path 还是 body？
对应 Spring 的哪三个注解？
