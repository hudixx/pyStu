## 题 1：写 JSON

在脚本同目录生成 `langs.json`，内容是一个列表，至少两项：

```json
[
  {"name": "java", "years": 30},
  {"name": "python", "years": 0}
]
```

要求：`Path` 拼接、`ensure_ascii=False`、`encoding="utf-8"`、`indent=2`。

## 题 2：读 JSON

把 `langs.json` 读回来，用 for 循环打印：

```text
java 学了 30 年
python 学了 0 年
```

## 题 3：路径判断

打印这三行：

- `langs.json` 是否存在（`exists()`）
- 它是不是文件（`is_file()`）
- 它的纯文件名（`name`）
