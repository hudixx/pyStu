# 转岗验收

主线和选修 B1 到 B6 已经批改完。这里把它们收成一个小服务，不另开一门课。

仍用进程里的假模型。不启动第 26 课的 mock 服务，不访问公网，不把密钥写进文件。

四课按顺序做。每一课有一个能跑的示例，练习是你自己的文件。参考答案等批改后再给。

| 课 | 验收的哪一条 | 先跑 |
|---|---|---|
| 01 流式、结构和重试 | 官方 SDK 那一套的形状：流式拼起来、JSON 收成对象、超时再试一次 | `验收-问答服务/01-流式结构重试` |
| 02 切块与黄金集 | 带引用。切块前和切块后，同一份题的通过数要变 | `验收-问答服务/02-切块与黄金集` |
| 03 步数上限 | 工具可以叫，叫不停就停。多数需求不该上 Agent | `验收-问答服务/03-步数上限` |
| 04 接口与假模型 | FastAPI、令牌、日志不带密钥、测试不打真模型 | `验收-问答服务/04-接口与假模型` |

第 5、6 条不用再写代码：提示注入、一次调用为什么要算 token，以及岗位没写训练就不要预训练。这些在第 46、47、30 课已经练过。
