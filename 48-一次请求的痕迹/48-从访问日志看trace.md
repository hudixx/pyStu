# 第 48 课：从访问日志看一次请求的痕迹

线上有人说「答错了」。只剩下那句回答，你查不出是检索空了、打错了模型，还是根本没打模型。一次请求要留下固定的几栏。

运行：

```bash
PYTHONUTF8=1 python 48-一次请求的痕迹/48_痕迹.py
```

- `退款几天`：出处含 `退款`，模型是 `未调用`，token 是 0
- `公司地址在哪`：出处是 `[]`，回答是「不知道」
- `你好`：走第 26 课的假模型，模型名是 `mock-chat`，`prompt_tokens` 大于 0

耗时每次不同，不拿它做断言。

---

## 1. 栏位是固定的，没有发生也要写

| 栏 | 检索路径 | 闲聊路径 |
|---|---|---|
| sources | 命中的出处，或 `[]` | `[]`，因为没检索 |
| model | `未调用` | 响应里的模型名 |
| token | 0 | `resp.usage`，不自己估了再当账单 |
| latency_ms | 你自己计 | 你自己计 |
| answer | 返回给用户的正文 | 同左 |

对照 access log。404 也要有一行，不能因为「没成功」就不记。空的出处是合法值，和漏写不是一回事。

密钥、用户手机号不进这行。上一课的 `redact` 用在 `question` 和 `answer` 上，如果它们可能含那些字段。

## 本课肌肉记忆

1. 答错了先看出处和有没有打模型
2. token 抄 `usage`，没有调用就写 0
3. 这行日志里不放密钥
