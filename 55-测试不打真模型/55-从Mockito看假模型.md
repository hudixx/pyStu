# 第 55 课：从 Mockito 看假模型

测试要证明两件事：不该打模型的时候一次都没打；该打的时候打的是你注入的假对象。不要在 CI 里访问付费接口。

运行：

```bash
PYTHONUTF8=1 python 55-测试不打真模型/55_假模型.py
```

`公司地址在哪` 返回「不知道」，调用次数是 0。`你好` 返回「回声」，调用次数是 1。

---

## 1. 假对象长得像真客户端

业务代码写 `client.chat.completions.create`。测试传入的对象也有这条路径，所以业务代码不用写 `if 测试`。

对照 Mockito 的 mock。你断言的是 `calls`，不是网络上有没有出去一个请求。假对象如果内部又去调了真的 SDK，这课就失败了。

地址题在调用之前就返回。这是第 35 课的拒答：没有资料，就不要打模型。
