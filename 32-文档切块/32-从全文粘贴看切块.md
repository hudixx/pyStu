# 第 32 课：从全文粘贴看切块

阶段七开始。RAG 是：先从你的文档里找出相关的几段，再让模型根据这几段回答。不是把 PDF 全文贴进提示词。

本课只做流水线的第一步：**切块**。不打模型，不花钱。

运行：

```bash
PYTHONUTF8=1 python 32-文档切块/32_切块.py
```

`手册.md` 是一份假的会员手册。后面几课都用它。

---

## 1. 为什么要切

| 整篇塞进去 | 切成小块 |
|---|---|
| 输入 token 很大，贵、慢（第 27 课） | 只把相关的几块送进去 |
| 模型容易抓错段落 | 一块一个出处，回答能引用 |
| 改一个数字要重塞全文 | 只重嵌那一块 |

一块不要大到像整章，也不要小到把「400-100-1000」切成两截。电话、订单号这种要能落在同一块里。

---

## 2. 先按结构，再按长度

假手册用 Markdown 的 `## 标题`。先按标题切：退款、客服、价格、订单号各一块。

一节仍然超长时，再滑窗：

- `max_chars`：一块上限
- `overlap`：下一块往回重叠几个字，避免句子正好切在边界上

对照：日志按条检索，不是把整个日志文件当一个字符串 `LIKE`。

---

## 3. 每块要有出处

`Chunk.source` 是标题，`Chunk.text` 是正文。后面回答必须能说「来自《退款》」，不能只给一段没有来源的话。

---

## 本课肌肉记忆

1. 不要把整份文档贴进 prompt
2. 先按标题/段落切，超长再滑窗，留重叠
3. 每块带着 source
4. 切太碎会把订单号、电话拆开
