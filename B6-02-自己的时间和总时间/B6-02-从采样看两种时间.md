# 选修 B6 第 2 课：从采样看两种时间

自身时间是这个函数自己的语句。总时间把它叫出去的函数也算上。父函数总时间大，常常是因为孩子慢。

运行：

```bash
PYTHONUTF8=1 python B6-02-自己的时间和总时间/02_两种时间.py
```

应看到：

```text
outer 自身小于总时间
inner 自身等于总时间
```

`outer` 只是 `return inner()`。时间在 `inner` 的循环里。

---

## 1. 已经在跑的进程

`cProfile` 要在它下面重新启动。线上那个进程不能停，就换 `py-spy`：从外面看它现在的栈，隔一会儿采一次。它不把每次调用都记下来，所以对程序的拖累小。

本课不安装 `py-spy`。Windows 上它经常要管理员权限。两种时间的差别，用 `cProfile` 就看得清。

`py-spy top --pid <进程号>` 是看正在跑的进程。不要为了这一课去对别的进程采样。
