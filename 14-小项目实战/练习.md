## 必做命令

```bash
PYTHONUTF8=1 python 14_练习.py add 买牛奶
PYTHONUTF8=1 python 14_练习.py add 学Python
PYTHONUTF8=1 python 14_练习.py list
PYTHONUTF8=1 python 14_练习.py done 1
PYTHONUTF8=1 python 14_练习.py list
```

行为要求见 `14-命令行待办.md`。摘要：

1. 数据文件：脚本同目录 `todos.json`
2. `add <title>`：追加，id 自增，打印 `已添加 #id title`
3. `list`：未完成 `[ ]`，已完成 `[x]`
4. `done <id>`：标记完成；id 不存在时打印错误并 **退出码非 0 或至少不 traceback**
5. `utf-8` + `ensure_ascii=False`
