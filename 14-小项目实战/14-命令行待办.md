# 第 14 课：小项目实战——命令行待办

把前面学过的拼成一个能用的小工具。方向按「先打基础」来：不接 Web、不上 pandas，做一个 **命令行待办**。

本课示例只演示零件（子命令、JSON 读写），**完整程序要你自己在 `14_练习.py` 里写**。这就是毕业题。

```bash
PYTHONUTF8=1 python 14-小项目实战/14_零件.py add --title 演示
PYTHONUTF8=1 python 14-小项目实战/14_零件.py list
```

## 你要做出来的成品

```bash
cd 14-小项目实战
PYTHONUTF8=1 python 14_练习.py add 买牛奶
PYTHONUTF8=1 python 14_练习.py add 学Python
PYTHONUTF8=1 python 14_练习.py list
PYTHONUTF8=1 python 14_练习.py done 1
PYTHONUTF8=1 python 14_练习.py list
```

期望大致：

```text
已添加 #1 买牛奶
已添加 #2 学Python
[ ] #1 买牛奶
[ ] #2 学Python
已完成 #1
[x] #1 买牛奶
[ ] #2 学Python
```

数据存在脚本同目录的 `todos.json`，关掉终端再打开还在。

---

## 建议的数据格式

```json
[
  {"id": 1, "title": "买牛奶", "done": false},
  {"id": 2, "title": "学Python", "done": false}
]
```

- `id` 从 1 起，新增时取当前最大 id + 1（空文件从 1 开始）
- `done` 是 JSON 的 `true/false`，对应 Python 的 `True/False`
- 文件不存在时当成空列表，不要崩溃

---

## 建议拆成的函数（对标 Java 的分层，但不必上 class）

| 函数 | 职责 |
|---|---|
| `data_path()` | 返回 `Path(__file__).with_name("todos.json")` |
| `load_todos()` | 读 JSON；文件没有则 `[]` |
| `save_todos(items)` | 写成 JSON，`ensure_ascii=False`，`indent=2` |
| `cmd_add(title)` | 追加一项并保存 |
| `cmd_list()` | 打印 `[ ]` / `[x]` |
| `cmd_done(todo_id)` | 找到 id 把 `done=True`；找不到打印错误，不要 traceback |

也可以写成 `class TodoStore`，用你更顺手的方式。第 06 课的 class 在这里正好用上。

## 子命令：`argparse` 的 `add_subparsers`

第 13 课是 `--name`。本课有 `add` / `list` / `done` 三个动作，用子命令：

```python
parser = argparse.ArgumentParser(description="命令行待办")
sub = parser.add_subparsers(dest="command", required=True)

p_add = sub.add_parser("add", help="新增")
p_add.add_argument("title", help="待办内容")

sub.add_parser("list", help="列出全部")

p_done = sub.add_parser("done", help="标记完成")
p_done.add_argument("id", type=int)
```

解析后：`args.command` 是 `"add"` / `"list"` / `"done"`。
用 `if args.command == "add":` 分支即可。

## 边界（做的时候要想一下）

1. 第一次运行，还没有 `todos.json`
2. `done 99` 没有这个 id
3. `add` 的 title 里有中文
4. 连续 `done` 同一条：已经完成的可以再标一次，或提示已完成——两种都行，在注释里写你选了哪种
