# 第 36 课：从回归测试看黄金集

改了切块长度、重叠或分数门槛之后，不要凭感觉说「好像更准」。准备一小份固定题目，每题写明应该命中哪一节，或者应该拒答。改完重跑。

运行：

```bash
PYTHONUTF8=1 python 36-检索黄金集/36_黄金集.py
```

五题都应是「对」，最后一行 `命中 5/5`。

---

## 1. 评的是出处，不是文采

| 题 | 期望 |
|---|---|
| 退款几天 | 退款 |
| 客服电话多少 | 客服 |
| 年度会员多少钱 | 价格 |
| SKU-8891 是什么 | 订单号 |
| 公司地址在哪 | 拒答（出处为空） |

这和 JUnit 一样：输入固定，期望固定。本课不把回答交给另一个模型打分。那个叫 LLM-as-judge，阶段九再说，而且裁判也会错。

五题很少，只够防止改切块时把电话和订单号切坏。生产要更多，但方法相同。

---

## 2. 什么算一次失败

实际出处和期望不一致，就是错。包括：

- 问退款却检索到价格
- 手册里没有的问题却返回了某一节（不该编）
- 把整篇当成一块之后，出处永远是「全文」，四道事实题会全部对不上「退款/客服/…」

所以黄金集逼你保持「一节一块、带标题」。这就是切块方式要能说清楚的原因。

---

## 本课肌肉记忆

1. 固定问题 + 期望出处，改完就重跑
2. 拒答也是期望的一种
3. 先评检索对不对，再谈回答好不好
4. 不要用「感觉更准」代替这张表
