# 第 01 课练习

先运行示例：

```bash
python 01_hello.py
```

然后自己新建一个文件 `01_练习.py`（不要改示例文件），完成下面 4 题。

---

## 题 1：入口与函数

写一个函数 `introduce(name: str, years: int) -> str`，返回：

```text
我是 {name}，学编程 {years} 年。
```

在 `if __name__ == "__main__":` 里调用它，打印返回值。
参数用你自己的名字，年限用你的 Java 年限即可。

## 题 2：真值判断

写一个函数 `label(value) -> str`：

- `value` 为假值时返回 `"空"`
- 否则返回 `"有内容"`

分别传入 `""`、`"hello"`、`0`、`1`、`None`、`[]` 看结果。
想一想：这和 Java 里必须写 `value != null && !value.isEmpty()` 差在哪？

## 题 3：故意写错一次缩进

把某个 `if` 下面的 `print` 少缩进 1 格，运行，把完整报错贴给我。
目的：让你亲眼看到 `IndentationError`，以后一眼能认。

## 题 4：对照题（口头即可）

用一句话回答：Python 的变量和 Java 的变量，最关键的差别是什么？
