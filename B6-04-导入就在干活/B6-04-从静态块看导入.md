# 选修 B6 第 4 课：从静态块看导入

`import` 会执行模块体。循环若写在那里，或者写在函数里又在模块体调用，每个新进程都要做一遍。

运行：

```bash
PYTHONUTF8=1 python B6-04-导入就在干活/04_导入.py
```

应看到：

```text
第一次导入 build 1
第二次导入 build 0
```

同一次进程里的第二次不会再跑 `build`。`sys.modules` 里已经有这份模块。

---

## 1. 第二次很快，不能说明启动不慢

测试文件里多写一次 `import`，看不到这笔代价。代价在进程刚起来的那一次：命令行、每个工人进程、每跑一轮测试的新进程。

想让导入变轻，就把工作放进函数，并且不要在模块体调用它。谁要用，谁再调用。

---

## 本课肌肉记忆

1. `import` 会跑模块体
2. 同进程第二次导入是缓存，次数是 0
3. 每个新进程都要再付第一次的代价
