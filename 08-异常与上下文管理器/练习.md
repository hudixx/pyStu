## 题 1：try / except / else

写函数 `parse_int(raw: str) -> None`：

- `try` 里 `int(raw)`
- 成功走 `else`，打印 `成功: {数字}`
- 失败 `except ValueError`，打印 `失败: {raw}`

分别调用 `parse_int("42")` 和 `parse_int("x")`。

## 题 2：自定义异常 + raise

写异常类 `AgeError(Exception)`。

写函数 `set_age(age: int) -> int`：`age < 0` 时 `raise AgeError("年龄不能为负")`，否则返回 `age`。

在 `main` 里用 try/except 调用 `set_age(-1)`，把异常消息打印出来。

## 题 3：with 写文件

用 `with` 把一行文字 `hudi 学 Python` 写到本目录的 `note.txt`（编码 `utf-8`），
再在另一个 `with` 里读出来打印。

不要手动 `close()`。路径可以用：

```python
from pathlib import Path
path = Path(__file__).with_name("note.txt")
```
