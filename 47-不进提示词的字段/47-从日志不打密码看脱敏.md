# 第 47 课：从日志不打密码看脱敏

用户会把手机号、密钥贴进问句。这些不能原样进提示词，也不能原样进日志。模型不需要它们才能回答「几天可以退」。日志用来排障，不用来保存秘密。

运行：

```bash
PYTHONUTF8=1 python 47-不进提示词的字段/47_脱敏.py
```

应看到手机号和 `sk-demo1234` 都被换成占位，`原文泄漏: False`。

---

## 1. 两道门是同一份 redact

```text
用户原文 → redact → 放进 user 消息
                 → 放进日志
```

只抹日志、提示词仍带密钥：密钥已经发给了模型服务商。只抹提示词、日志仍带密钥：日志系统等于第二份密码本。

对照：`application.yml` 里的密码不进 git，也不进 access log。这里多一步，因为秘密是用户随口贴进来的，不是你的配置。

手册上的 `400-100-1000` 是公开客服电话，正则对不上 `1` 开头的 11 位手机号，不会被误伤。公开资料和用户隐私分开看。

本课的正则很短，挡的是课里这种形状。生产里身份证、银行卡还有别的形状，原则相同：先列出不能出现的字段，再写替换，而不是指望「记得别 print」。

---

## 本课肌肉记忆

1. 提示词和日志用同一份脱敏
2. 用户贴进来的密钥、手机号，不是回答问题所必需的
3. 公开的客服电话可以留在手册里
