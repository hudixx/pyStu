# 选修 B5 第 3 课：从 MDC 看请求号

同一个请求的号，下游不用参数也能读到。这笔结束，号要还回去。下一次没放号的代码，不能读到上一笔。

对照 MDC。`MDC.clear()` 放在 `finally`。这里用 `contextvars`，不用模块里的一个全局字符串。

运行：

```bash
PYTHONUTF8=1 python B5-03-同一个请求一个号/03_追踪.py
```

应看到：

```text
入口 T-1
下游 T-1
结束后 -
```

---

## 1. set 的返回值要留着

`trace_id.set("T-1")` 返回一块 token。`reset(token)` 用它回到 set 之前的值。不要自己再 `set("-")` 来假装还回去。外面如果已经有号，你这一笔只应该撤掉自己放上的那层。

`downstream` 没有请求号参数。它调用 `trace_id.get()`。这就是不用每个函数都多加一个参数的原因。

模块级的一个字符串整个进程只有一格。两笔请求叠在一起，后写的盖掉先写的。`contextvars` 按任务各留一份。下一课把两笔放在同一条线程上看这个差别。
