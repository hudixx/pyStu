## 题 2：引用还是拷贝

先在纸上（或注释里）写出下面程序的两行输出，再运行验证：

```python
a = ["java", "python"]
b = a
c = a[:]
b.append("go")
c.append("rust")
print(a)
print(c)
```

在文件顶部用注释写你的预测，再 print 对照。

## 题 3：dict 安全取值

写函数 `city_of(user: dict, default: str = "未知") -> str`：

- 有 `"city"` 这个 key，返回它的值
- 没有则返回 `default`

分别传入 `{"name": "hudi", "city": "上海"}` 和 `{"name": "hudi"}` 验证。
不要用 `user["city"]` 硬取（缺 key 会 `KeyError`），用 `get`。
