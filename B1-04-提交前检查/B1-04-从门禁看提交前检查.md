# 选修 B1 第 4 课：从门禁看提交前检查

第 25 课会跑 `ruff` 和 `mypy`。这一课把它们当成提交前的门：退出码不是 0，就不要提交。

先确认检查器还在（装过一次就不用再装）：

```bash
python -m pip install -e ".[lint]"
PYTHONUTF8=1 python B1-04-提交前检查/04_检查.py
```

应看到：

```text
本文件 ruff 0
本文件 mypy 0
坏例子 ruff 1
坏例子 mypy 1
```

机器上如果 ruff 或 mypy 没装，前两行不会是 0。先装 `.[lint]`。

---

## 1. 门和测试不是同一件事

| 命令 | 做的事 | 不做的事 |
|---|---|---|
| `ruff check` | 未使用的变量、明显写错 | 不运行 `main` |
| `mypy` | 注解对不上 | 不运行 `add("a", "b")` |
| `pytest` | 真的调用你的函数 | 不管你有没有跑过上面两个 |

坏例子里的 `add("a", "b")` 如果真的执行，会得到 `"ab"`。mypy 仍然报类型不对。检查器只读文件。

坏例子放在临时文件里。不要在仓库里留一份故意不过的 `.py`，不然以后扫整个目录会一直红。

类型对不上时，先改代码。`# type: ignore` 是留给第三方烂注解的，不是第一反应。

组里如果用 pre-commit，也是在提交时跑这两条。这一课不往你的 git 里装钩子。

---

## 本课肌肉记忆

1. 提交前 ruff 和 mypy 都要是 0
2. 检查器不执行业务代码
3. 先改代码，不要先写 `type: ignore`
