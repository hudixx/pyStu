# 第 54 课：从 JWT 看请求头

接口要知道是谁在调用。客户端把令牌放在 `Authorization: Bearer ...`。服务端检查签名，不相信客户端口头说自己是谁。

运行：

```bash
PYTHONUTF8=1 python 54-谁能调用/54_鉴权.py
```

无令牌是 `401`。用密钥签发给 `hudi` 的令牌是 `200`，响应里的用户是 `hudi`。改过一个字符的令牌是 `401`。

---

## 1. 三段

```text
header.payload.signature
```

`payload` 里是 `sub`，本课就是用户名。`signature` 是用 `APP_SECRET` 对前两段算出的。改了 payload，签名对不上。

这不是让你以后自己写 JWT。结构看懂即可。生产用 PyJWT 这种库。密钥放环境变量 `APP_SECRET`，不要写进仓库。代码里的 `dev-secret` 只为了没设环境变量时这课还能跑。

令牌不是密码。密码用来换令牌。之后的请求带令牌，不再把密码放进每个请求。令牌泄漏了要作废。本课没有作废列表，知道有这件事即可。

## 本课肌肉记忆

1. 没有令牌、令牌被改过，都是 401
2. 用户名从令牌里解出来，不从查询参数信任
3. 签名密钥不进 git
