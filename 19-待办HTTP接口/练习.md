## 必做接口

1. `GET /todos` → 数组，元素含 `id` / `title` / `done`
2. `POST /todos` body `{"title": "买牛奶"}` → 201 或 200，返回新建对象
3. `POST /todos/{todo_id}/done` → 返回更新后的对象；没有这个 id 则 404

持久化到本目录 `todos.json`。id = 当前最大 id + 1。
