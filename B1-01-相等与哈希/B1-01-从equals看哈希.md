# 选修 B1 第 1 课：从 equals 看哈希

两个 `Sku("SKU-8891")` 应该算同一个货号。没写相等时，Python 比的是不是同一个对象。

运行：

```bash
PYTHONUTF8=1 python B1-01-相等与哈希/01_相等.py
```

应看到四行：

```text
没写相等 False 2
只写相等 TypeError
写全了 True False 1
改过之后 False True
```

---

## 1. 和 Java 不一样的地方

| 写法 | Java | Python |
|---|---|---|
| 都不写 | `equals` 比引用 | `==` 比是不是同一个对象 |
| 只写相等 | `HashSet` 可能装两份，而且按值找不到 | 放进 `set` 直接 `TypeError` |
| 两个都写 | 值相同就是同一个键 | `==` 为真，`set` 里只留一个 |

`__eq__` 里类型不对时返回 `NotImplemented`，不是 `False`。`False` 表示「我确定不相等」。`NotImplemented` 表示「我不会比，换对方试试」。

`__hash__` 必须用和 `__eq__` 同一组字段。这组字段放进 `set` 之后不能改。改了以后，`in` 按新哈希去找，找不到；对象其实还在集合里。`list` 不能参与哈希，它不能当字典的键。

## 本课肌肉记忆

1. 写了 `__eq__` 就要写 `__hash__`
2. 哈希用的字段保持不变
3. `==` 看值，`is` 看是不是同一个对象
