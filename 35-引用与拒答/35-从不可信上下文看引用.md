# 第 35 课：从不可信上下文看引用

检索回来的块是**数据**，不是新的系统指令。回答必须能指出来源。库里没有的事，说不知道，不要让模型凭空编。

运行：

```bash
PYTHONUTF8=1 python 35-引用与拒答/35_引用.py
```

「退款几天」「SKU-8891」应带出处。「公司地址在哪」手册里没有，应是 `不知道`，出处是空列表。

---

## 1. 没命中就不要打模型

```text
有相关块 → 把块和来源放进提示词 → 再生成
没有     → 直接「不知道」
```

对照：缓存未命中不要去编一个用户。空结果是合法结果。

本课回答先用命中的原句，末尾写 `（来源：退款）`。真环境把这一句换成第 26 课的 `chat.completions.create`，system 写成「只根据下面的资料回答，不知道就说不知道」。资料放在 user 里，**不要**拼进 system。用户问句和检索正文都是数据（阶段九会讲提示注入）。

---

## 2. 分数要有门槛

Top-1 永远有「最不像里相对最像」的那块。问公司地址时，退款块可能仍是最高分，但分很低。

所以：关键词命中，或向量分 ≥ 0.45，才算相关。否则拒答。

0.45 是**这套假向量**上试出来的。换真 embedding 必须重测，不能把 0.45 抄到生产。

---

## 本课肌肉记忆

1. 回答带来源
2. 检索不到就说不知道，并且不调用模型
3. Top-1 不等于相关，要有分数门槛
4. 资料是数据，不是系统指令
