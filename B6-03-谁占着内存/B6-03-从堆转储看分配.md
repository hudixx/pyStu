# 选修 B6 第 3 课：从堆转储看分配

函数慢，用上一课的时间。内存涨，用 `tracemalloc` 看是哪一次分配。两件不要混。

运行：

```bash
PYTHONUTF8=1 python B6-03-谁占着内存/03_内存.py
```

应看到：

```text
占着 800000
已释放
```

本机是 64 位。十万个指针，每个 8 字节，是 800000。不是十万份「买牛奶」的文字。

---

## 1. 删掉之后还在不在

`get_traced_memory()` 给出的是现在还占着的字节。列表还在变量里，差就是这十万个指针。`del` 之后再读，应比持有时小，所以打印「已释放」。

忘记 `del`，第二行会是「还在」。剖析时间看不出这件事：分配本身可以很快，字节却留着。

## 本课肌肉记忆

1. 慢用时间，涨用分配
2. 重复同一个字符串，涨的是指针列表
3. 删掉之后再量一次，确认还在不在
