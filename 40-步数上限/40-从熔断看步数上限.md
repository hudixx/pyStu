# 第 40 课：从熔断看步数上限

Agent 就是一个循环：模型要工具 → 你执行 → 结果喂回去 → 再问模型。不停的话，每一圈都是一次付费 HTTP。上限写在 **你的 for** 里，不写在提示词里。

运行：

```bash
PYTHONUTF8=1 python 40-步数上限/40_上限.py
```

- `列出待办`：模型调用 2 次，工具执行 1 次，正文以 `已根据工具结果回答:` 开头
- `TOOL:LOOP`：模型调用 3 次，工具执行 3 次，停止原因是 `步数用尽`
- `TOOL:SLOW`：第一次请求睡 2 秒，返回后发现已经超过 1 秒，停止原因是 `超时`，模型调用只有 1 次

循环在 `38-工具调用入门/agent_loop.py`。

---

## 1. 两道闸不是同一个 timeout

| 闸 | 谁写的 | 拦住什么 |
|---|---|---|
| `max_steps=3` | 你的 `range` | 模型一直要工具时，最多再问它 3 次 |
| `deadline_s` | 你的秒表 | **下一轮**请求发出去之前，时间到了就停 |
| 客户端 `timeout=10` | 第 30 课 | 单次 HTTP 太慢，把这一次掐断 |

`TOOL:SLOW` 那一道闸，等的是已经发出的请求回来，然后拒绝发下一轮。它不会把服务器上那 2 秒从中间取消。取消单次 HTTP 仍用第 30 课的 `timeout=`。

提示词里写「请不要超过 3 步」没有用。假模型的 `TOOL:LOOP` 根本不看这句话。对照：熔断次数配在 Resilience4j 上，不配在下游服务的口头承诺里。

---

## 2. system 不是草稿纸

循环只允许追加 `assistant` 和 `tool`。`messages[0]` 保持你启动时写的那句。工具结果放进 system，就等于让外部数据改你的配置。阶段九会专门讲注入；这里先把位置放对。

---

## 本课肌肉记忆

1. 步数是 `range`，不是提示词
2. 循环停了要能说出是「回答 / 步数用尽 / 超时」里的哪一种
3. 每多一轮模型，就多一次调用
